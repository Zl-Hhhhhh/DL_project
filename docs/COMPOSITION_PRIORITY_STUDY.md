## 样本与约束

复用冻结开发集中的全部 8 张 `status=ok` 图片，另加之前测试过的官方咖啡杯。原开发集中的 3 张主体截断和 1 张低置信度图片保持跳过，记录在 `summary.json`，没有按新效果好坏筛选源图。

9 张源图共 72 个计划槽位，生成 **51 个版本（含 9 个原图对照）**；21 个裁切槽位不可行。所有实际输出为 512×512。独立 PNG 不含说明文字或参考线；对照 JPG 仅用于浏览。

- 摄影路径只做裁切和背景调色，不移动主体或生成内容。裁切保留全部主体掩码及约 1.5% 的边界，不使用补边区域凑构图。
- 三分参考点采用**主体包围框中心**，不是人物眼睛或脸。裁切目标距离容差为归一化坐标的 0.045，目标和实测误差均写入 JSON。
- 背景饱和度倍率固定为 0.15。主体颜色相对于同一几何变换下的原图逐像素保持一致；缩放本身会发生插值。
- 拼贴采用米白纯色背景，主体最长边占画布的 55% 或 38%，分别代表本轮的较紧凑和较疏朗方案。它会主动移除原背景，是平面拼贴候选，不属于保留场景的摄影处理。
- 留白评估使用目标对侧的 25% 宽度，分别记录主体占用比例与背景 Canny 边缘密度。排除补边区和主体附近窄边界；这里的边缘密度只是纹理杂乱度的近似，不是美学分数。

## 观察与推荐

**最先值得接入的是“主体保色＋背景饱和度”**。几何不变，便于用户判断效果，也能与已有原色、双色方案放在同一类颜色控制中。咖啡杯背景平均 HSV 饱和度由 0.542 降至 0.106，主体 RGB 不变；但黑猫本身颜色较暗，突出效果较弱，不能声称所有主体都会更鲜明。

**“居中／三分位置＋主体占比”适合一起作为拼贴构图控制。** 咖啡杯在三分布局中，较大和较小版本的主体面积占比分别为 16.7% 和 8.0%，右侧留白区主体占用均为 0，纯色背景边缘密度为 0。这证明控制量生效，不证明面积越小、留白越大就越好看。狗依赖窝作为场景支撑、猫的身体受到键盘遮挡，直接抠出后存在悬空或形状不完整的观感；原分割通过并不等于适合独立拼贴。

**三分裁切作为有条件的候选。** 8 张开发图均无法满足本轮正方形三分裁切约束；只有杯子示例成功。主体大、原始画幅窄或依赖环境的照片，不能靠裁切保证任意构图。居中裁切也可能损失其他对象或上下文，即使主掩码完整；本轮没有将这些结果自动评为更优。

组合顺序建议：先提供颜色控制；再提供拼贴位置与主体大小；摄影路径只在主体可完整保留时提供构图裁切。重复、切片、方向估计和学习排序器留作后续。三分点误差、主体占比、留白区主体占用、边缘密度与饱和度可作为后续排序器的解释性特征，仍须用独立人工偏好检验价值。

## 界面部署更新（2026-09-18）

上述 1、2 两类功能现已接入本地界面，在「拼接 → 处理效果」下选择：

- **原图拼接**：原有双色／原色和左右／居中构图行为保持原样，仍为默认。
- **主体保色**：背景饱和度 0–100%，默认 15%；主体位置不变、掩码内原色保留。100% 返回原图画布颜色，0% 将背景变成灰度。
- **纯色拼贴**：移除原背景、使用米白底；主体保持原色。可选居中和四个三分交点，主体最长边占画布 30–60%，默认 55%。小主体对应更多留白。

两项新效果均支持 512／1024。切换效果会显示相应参数，隐藏不适用的旧配色和构图控制；修改参数会使旧下载结果失效，重新生成后可下载新图。三分位置仍以主体包围框中心为参照。分割可能包含误差或缺失被遮挡部分，控件不会补全原图中看不到的主体。

仍可选择 CollageRL 后处理，但它会再次重构整张图，因此「主体像素保持」仅适用于后处理前的结果。后处理默认关闭。

API `/api/generate` 在 `mode=collage` 下新增 `collage_effect`：`existing`（默认）、`color_focus`、`poster`。后两者分别使用 `background_saturation`（0–1），以及 `poster_position`（`center`、`top_left`、`top_right`、`bottom_left`、`bottom_right`）与 `subject_size`（0.30–0.60）。参数写入任务目录的 `params.json`，现有 `replay` CLI 已支持新效果。旧请求、冻结开发集与旧参数重放路径保持兼容。

验证：40 项测试通过；真实浏览器完成两个效果 × 两种尺寸共 4 个生成任务，下载 PNG 的尺寸和 SHA-256 均与服务端一致，全部参数重放哈希相同。主体保色检查通过，纯色拼贴的三分点误差小于 2 像素对应的归一化距离；留白区没有主体侵入。另验证了识别框阈值、键盘选项切换、结果失效，以及 375／320 像素宽度无横向溢出，浏览器无 JavaScript 错误。
