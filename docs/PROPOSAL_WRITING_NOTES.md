## 2. 建议主线及其研究价值

推荐英文题目：**Object-Aware Preference Learning for Controllable Image Collage**。

中文含义：**面向可控图像拼贴的对象感知偏好学习**。

核心问题是：给定同一原图的一组候选及明确的编辑目标，在标注有限时，显式加入原图与编辑结果中的主体信息，是否比只看全图更容易学到偏好？构图和配色特征能否进一步减少所需标注？

这与“实现三分法”不同：三分法、居中、留白和配色提供可控候选及可解释特征；真正训练和研究的是小型排序网络。冻结视觉编码器后训练排序头仍属于深度学习，但必须报告其泛化、消融和标注效率，不能只展示界面效果。

已有文献研究构图与风格属性辅助审美评估，因此不能把“加入构图特征”本身宣称为首创。可探讨的具体问题是同一原图的多个编辑结果、目标条件、主体对应信息和有限标注的组合是否有效。草稿没有声称这是已有文献从未研究过的方向；正式报告前仍需补充候选排序和偏好学习文献。

建议检验两个假设，允许实验否定它们：

- H1：在相同标注预算下，主体特征能提升全图特征排序器的测试集偏好一致率。
- H2：显式设计特征的收益在低标注预算下更明显，但是否优于固定构图规则需要实验验证。

## 4. 建议实验如何落地

建议第一版固定为海报拼贴候选排序，统一输出 512×512。1024×1024 保留为展示选项，避免扩大变量。主体位置、大小、留白、保色／受控配色作为候选变化；摄影裁切和海报拼贴不要混在同一个偏好任务里，以免目标不同造成无法解释的比较。

建议收集另外 120 张原图，按来源分为 80／20／20 张训练、验证、测试图，排除当前 12 张开发图和官方杯子示例。先按来源及近重复分组，再生成候选，禁止同一原图的不同编辑进入不同集合。这里的独立性针对下游实验，不能声称公开预训练模型从未见过这些原图。若沿用 COCO，记录图片 ID、来源及许可信息。

每张图预先分配一个编辑目标，在构图目标和颜色目标之间尽量平衡；各目标在三个集合都有覆盖。每张生成 8 个候选，共约 960 个候选；每张标注 8 对，共约 960 次比较，另抽约 10% 重复检查一致性。这是工作量估计，不是现有数据。将配对设计成覆盖全部候选的连通图，并加入难区分的比较，避免所有标签都由明显违反目标的候选主导。

候选和目标一旦冻结，所有排序器共享它们。目标由明确的说明给出，例如“主体偏左，右侧留白，保留原色”；人工判断在这个目标下哪个结果更合适，而不是强制认为某个三分交点永远最好看。记录平局，不能把构图规则生成的伪标签当作独立审美评价。

| 比较项 | 输入／机制 | 用途 |
| --- | --- | --- |
| 随机、固定规则 | 随机选择；预先固定的几何与颜色规则 | 检查学习方法是否真的有价值 |
| G | 原图与候选的全图特征、目标条件 | 深度学习基线 |
| G＋O | 增加原图与候选的主体裁切特征 | 检查主体信息的增量作用 |
| G＋D | 增加位置、面积、颜色等设计特征 | 检查显式规则特征的作用 |
| G＋O＋D | 同时加入两类特征 | 检查互补性 |

所有学习方法使用相同排序头结构；被消融的输入块置零，减少网络规模差异的干扰。推荐冻结 DINOv2 ViT-S/14，缓存特征，训练小型 MLP；该配置需要后续实际接入及显存测试。排序训练使用成对损失：偏好候选分数应高于另一个候选；平局先不进入该损失，单独报告比例。

标注预算采用每张训练图 2／4／8 对，训练图数量不变，标签子集嵌套，验证和测试对固定。每种配置训练 3 个随机种子。主要指标为非平局测试对的偏好一致率，并报告有效覆盖与平局比例；补充隐藏方法名称、随机左右顺序的首选结果比较。置信区间按原图重采样，不能把同一原图的多个候选当成独立样本。20 张测试原图只能支持小规模探索，需展示区间并谨慎解释类别差异。

第一版标注由项目作者完成，并明确称为作者偏好研究；重复标注估计自身一致性，不等于多人一致性。若之后计划招募外部评价者，应先向教学团队确认课程允许范围，再扩展实验承诺。

特征还需避免无效输入：纯色背景上的边缘密度通常没有区分力；所有候选都完整保留主体时，可见比例可能恒定。这些量可以做生成约束，但只有存在实际变化时才作为排序特征。不能因固定规则分数提高，就宣布学习模型更符合人类审美。

引用文献的完整链接见英文草稿。CollageRL 对应论文的正式题目是 *Neural Collage Transfer: Artistic Reconstruction via Material Manipulation*；DINOv2 提供通用视觉表示，并不是现成的审美评分模型。
