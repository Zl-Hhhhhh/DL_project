# 开发协议与来源

## 开发数据

来源为 [COCO 官方数据集](https://cocodataset.org/#download) 的 train2017。
`scripts/prepare_dev.py` 使用官方 instance annotation 的非 crowd 标注筛选，固定种子 2012；主体标注面积占比为 12%–65%、框两边均至少 100px。
固定槽位为 4 张 person、cat/dog/bird/horse 各 1 张、chair/cup/potted plant 各 1 张，以及 1 张触边 teddy bear。选择在模型推理前完成，不按生成效果换图。
11 张要求标注框离边界至少 5px，最后一张有意保留截断压力案例。
背景复杂度未使用人工标签；每张的背景拉普拉斯边缘能量仅为诊断值，待人工核验简单/复杂场景覆盖。

每张原始文件只读使用；manifest 包含 COCO ID、原下载地址、Flickr 地址、原始尺寸、SHA-256、类别、许可名称及 URL。
开发源图不得进入正式 80/20/20 划分，也不得与摄影集混用。入口检查源 ID、相同文件哈希和已标注的 capture_group；近重复检测仍需后续人工核验，不能声称已自动清除所有近重复。
COCO 预训练可能见过这些图，开发结果不代表未知图泛化。
COCO 自定义图片域名的 HTTPS 证书存在主机名不匹配，脚本访问同一公开 S3 bucket 的 path-style HTTPS 地址，不关闭证书验证。

## 分割

使用固定 `ultralytics==8.3.203` 和 `yolov8n-seg.pt`；[YOLOv8 官方模型说明](https://docs.ultralytics.com/models/yolov8/)与[实例分割说明](https://docs.ultralytics.com/tasks/segment/)。
权重来自 Ultralytics 官方 assets 的 v8.3.0 release，下载后写入本地 SHA-256；后续运行不接受静默换权重。
自动选择指定类别中 mask 面积最大的置信度不低于 0.50 的实例；可通过 CLI 的实例 ID 改选。
模型预测保留低至 0.10 的检测以区分低置信度和未检出；不把低置信度对象自动提升为有效主体。
保留原始掩码孔洞和连通分量，不自动补人体缺失部位。掩码碰到原图有效区域边缘的 2px 范围时默认返回 `subject_truncated`。
透明像素在检测前合成白底，在掩码中排除；图像先根据 EXIF 转正，再等比补边。源图文件始终不写入。

## 候选和可重放性

双色 v1 将亮度映射为两个指定色端点，混合 0%、25% 或 50% 原纹理，主体最长边为画布的 50% 或 65%。这是本项目人工设定的原型调色表，不冒充从网络热度或参考作品自动学得的风格。
候选由源 ID、构图和全局 seed 的 SHA-256 派生任务种子；固定参数网格打乱后交替两个尺度，最多尝试 32 次，保存前 8 个合法结果。
对象框中心取目标中心加 -4%、0% 或 +4% 横向偏移；评价记录最终可见 mask 质心误差，因此质心与框中心可以不同。
左构图的最右 25% 与右构图的最左 25% 为留白区，主实例不得进入；保留至少 90% 的变换后 mask 面积。
规则选择依次最小化质心位置误差、最大化可见比例、接近 25% 纹理强度。它没有学习审美。
重放从保存的 source/mask PNG 与 JSON 生成输出并验证文件哈希；固定候选排序通过规则函数验证；指标从 result.json 重新汇总。
模型原始分割的跨平台位级确定性未作承诺，重放不重新调用模型。

## 许可与研究边界

Ultralytics 代码和模型的使用应遵循其 [AGPL-3.0 / 许可说明](https://www.ultralytics.com/license)。数据图片依照各自许可，不能把全部 COCO 图片视为同一个授权。
本阶段没有付费 API、云服务、账号体系或 NPU 依赖，也未安装 LaMa、DINOv2、额外扩散模型。
独立风格示例板、人工 mask 核验和教学团队关于 AI 使用/披露的要求仍按 `PROJECT_PLAN.md` 后续落实。
